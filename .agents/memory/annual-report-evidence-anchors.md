---
name: Annual-report evidence anchors
description: How fixed-document report adapters retain strict evidence validation while covering precise financial-statement disclosures.
---

For a preverified, fixed annual report, evidence packs may include explicit anchors to relevant chunks when generic keyword ranking misses the exact statement or table row needed for a required analysis section. Anchor conclusions must retain the source's exact numeric formatting and explicitly label the accounting basis when financial figures are involved.

**Why:** Generic terms such as inventory, payables, and industry context can rank operational prose above the financial-statement row. Relaxing citation or basis validation to compensate would risk unsupported conclusions.

**How to apply:** Use an in-document, source-locked anchor only for a directly supported disclosure. Keep it inside the established evidence pack, cite the original chunk, and continue to publish an explicit “not established” conclusion when the report does not support the claim.
